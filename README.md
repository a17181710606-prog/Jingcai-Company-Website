# Jingcai Company Website

Phase B project skeleton for an internal-first equipment management and showcase system.

## Quick start

1. Copy `.env.example` to `.env.local` and fill in your Supabase keys.
2. Install dependencies with `npm install`.
3. Run `npm run dev`.

## Current scope

- Next.js App Router with separate site/admin route groups
- Admin middleware guard and demo login cookie flow
- Supabase browser/server client scaffolding for next integration step
- Inventory dashboard and CRUD route placeholders aligned to the planning docs
