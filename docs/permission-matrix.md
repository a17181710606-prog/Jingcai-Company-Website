# Permission Matrix

## 1. 角色定义

### Public Visitor
- 未登录访客
- 只能访问前台公开内容

### Editor
- 内容编辑人员
- 主要维护服务、案例、AI 项目等展示内容

### Warehouse
- 仓库/调度角色
- 负责库存状态、出入库、项目设备调配

### Admin
- 运营管理员
- 管理核心业务数据与后台日常运营

### Super Admin
- 拥有系统最高权限
- 管理用户与全局配置

## 3. 模块级细化说明

## 3.1 Equipment

### Public Visitor
- 只可查看 `is_public = true` 的设备公开信息

### Editor
- 默认不可编辑设备库存信息
- 如业务需要，可读取公开展示字段用于内容编排

### Warehouse
- 可查看全部设备
- 可更新状态、位置、项目关联、图片
- 不可修改采购成本、公开发布策略等敏感字段

### Admin / Super Admin
- 拥有完整设备 CRUD 权限

---

## 3.2 Inventory Logs
- 任何涉及状态变更、出库、入库、项目分配的动作都应自动生成日志
- Warehouse/Admin/Super Admin 可查看
- 普通角色不应删除历史日志

---

## 3.3 Content Items
- Editor 可维护内容草稿
- Admin/Super Admin 负责最终发布控制
- Public Visitor 只能查看 `is_published = true` 内容

---

## 4. RLS 实施建议

### 4.1 判断维度
建议通过以下信息综合判断权限：
- `auth.uid()`
- `profiles.role`
- 数据上的 `is_public` / `is_published`

### 4.2 典型策略
- `select equipment`：公开用户仅读 `is_public = true`；后台角色读全部
- `update equipment.status`：仅 `warehouse/admin/super_admin`
- `insert inventory_logs`：仅后台角色
- `insert/update content_items`：仅 `editor/admin/super_admin`
- `publish content_items`：仅 `admin/super_admin`

---

## 5. 审计要求
以下操作建议保留审计记录：
- 用户登录
- 设备创建/编辑
- 状态变更
- 图片上传/删除
- 项目设备关联/解除
- 内容发布/下线
- 权限调整
